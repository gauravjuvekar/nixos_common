name: nix-fmt
description: Run nix fmt after making any changes in this repository. Use for every task that edits repository files, including documentation and skills.
---

Always run `nix fmt` from the repository root after making changes and before reporting the task complete. If you make further edits, run it again.

Review any changes made by the formatter. If formatting fails, resolve failures caused by your changes and rerun it; report any remaining blocker.
